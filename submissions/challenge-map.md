# Challenge and dashboard mapping

Snapshot: September 29, 2026. All entries are pending. Theme alignment is
separate from eligibility, submission acceptance, and reward credit.

| Route | Official source | Reusable material | Remaining requirement | Status |
| --- | --- | --- | --- | --- |
| Dashboard activities | [Activities](https://hacktoberfest.com/activities/) and participant dashboard | Public repository and demo evidence if requested | Exact activity, participant action, and dashboard confirmation | Pending participant review |
| DEV weekend | [Challenge page](https://dev.to/challenges/hacktoberfest-weekend-2026-10-01) | Build-log draft and runnable examples, if relevant | Published prompt, template, tags, eligibility, and entry | Awaiting prompt |
| DEV Week 1 | [Challenge page](https://dev.to/challenges/hacktoberfest-week1-2026-10-05) | Skill and optional prompt-specific extension | Published rules, existing-work policy, required tools, and entry | Awaiting details |
| Later DEV rounds | [Challenge index](https://dev.to/challenges) | Same core; separate entry narrative | Each round's prompt and deadline | Awaiting details |
| Global Hack Week | [Event page](https://events.mlh.com/events/14553-global-hack-week-open-source) | Offline demo or justified new adapter | Registration, selected challenge requirements, and accepted submission | Awaiting challenges |

For each selected entry, make a copy of `entry-template.md` and record:

- Exact prompt and official rules URL, checked date, and deadline with timezone.
- Required activity or challenge identifier and submission format.
- Whether previously built work is allowed and what was built during the window.
- Required open-source tool/model and proof of actual use, if applicable.
- Requirement-to-artifact mapping, demo instructions, and validation results.
- Submission URL, platform acceptance, and dashboard credit, each separately.

A PR, test result, or public build log is evidence of project work; none is
claimed as reward credit without the relevant activity requirements.
