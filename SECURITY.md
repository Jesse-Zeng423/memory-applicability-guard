# Security and privacy

Do not submit credentials, authentication headers, host-specific paths, raw request/response logs, response identifiers, private evaluator labels, human rationales, or real personal memories.

The Skill and tests make no network or model API calls and require no secrets. The helper uses only supplied structured JSON and the Python standard library. Report a suspected exposure privately to the repository owner before opening a public issue; never include the suspected secret in the issue body.

This prototype is not a safety control and must not autonomously approve high-risk decisions.
